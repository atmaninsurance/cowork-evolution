## Deltas

### A. `orchestrator.sh` — red-line gate (CLD-00085)

- **A1 — scan surface.** `red_line_hit()` evaluates ONLY the artifact under judgment for the current
  gate decision: the quarantined intake/task content and (at enactment) the decision sidecar. It must
  NEVER scan the OI spine — the spine is an append-only findings record that accumulates V/D's own
  prose, so any spine token poisons the item permanently (the defect).
- **A2 — diagnosis.** When the gate fires, the escalation log line records which token matched, in
  which file, with line/context — no more reconstructing which string tripped it.
- **A3 — contradiction FLAG.** When a V/D verdict is the clean auto-route match
  (`variation=none`, `questions=0`, `recommend=route`) and the item is nevertheless escalated, emit an
  explicit FLAG line naming why (which gate, which token, which file) so a blocked auto-route can never
  masquerade as ordinary conservatism again.
- **A4 — scope limit.** Do NOT attempt a read-vs-write distinction inside the artifact itself in this
  pass: a task whose own content names a governance file still escalates (correctly conservative).
  That refinement belongs to the eventual red-line DEC (CLD-00073's boundary). The fix here is the
  scan surface, not the token semantics.

### B. `orchestrator.sh` — deliverable-path rider (CLD-00087, David's ruled direction)

### C. `lint-transcripts.py` — sentinel continuity + two new checks (CLD-00086)

- **C1 — scope the turn count.** The `sent_n != max_turn` comparison must count only the document's
  OWN turn headers, matching how `parse_sentinel()` already scopes. The item's fix sketch offers two
  shapes (own-document header marking; stop-at-first-embedded-content-boundary) plus the cheap
  quoted-region exemption — choose what survives the evidence fixtures (the `6d5a2d18` and `2d767e01`
  patterns: own sentinel/header agree at 1, embedded foreign turns and a foreign foot sentinel present).
- **C2 — diagnosis.** When the check fires, report the line number of the max-turn header and whether
  it sits inside a quoted/embedded region.
- **C3 — seed-staleness missed-flush FLAG** (design note, 2026-07-26): `remote_` file AND sentinel
  still `AFTER_TURN_0` AND no `[SOFT-CLOSE]`/`[SWEEP]` marker AND header `Live capture started` date
  earlier than the lint-run date → FLAG "missed flush — contingency fire never delivered". The marker
  condition prevents the false positive on a one-incomplete-turn chat whose successful soft-close
  pushed a header-only file WITH a marker.
- **C4 — ledger cross-check FLAG:** a `remote_` transcript for the lint's target day with neither a
  line in `~/Claude/Scheduled/nightly/remote-contingency-ledger.md` nor a close marker → FLAG "fire
  never ran or bridge down" — distinct message text from C3.
- **Scope discipline for all of C:** the marker/sentinel/header tests read the document's own
  foot/header regions — never whole-text grep — or these checks inherit the exact quoted-content false
  positives this item exists to kill.
